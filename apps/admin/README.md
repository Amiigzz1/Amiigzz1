# majlis-admin

Next.js dashboard for internal moderation, user administration, and withdrawal review.

Implemented in Phase 5. This directory currently holds the package manifest so
the workspace resolves and CI can pick it up once scaffolding begins.

## Planned routes

- `/login`
- `/users` — search, ban, unban, transactions
- `/rooms` — live list, force-close, reports
- `/moderation` — flagged messages, flagged voice clips
- `/withdrawals` — approve/reject KYC-cleared requests
- `/appeals` — 48-hour ban review queue
- `/analytics` — DAU, MAU, revenue, top rooms
